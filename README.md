# Final Game: Dodge Reckless Drivers Simulator 
Red Block -> Reckless Drivers; Can Move in Random Directions at any given time.
Orange Block -> Normal Drivers; Moves only in a straight line towards the player.
Blue Block -> Player 
Yellow Circles -> Coins to Increase Score

'W' to jump. A jump will allow the player to be above all the cars.
'A' / 'D' to move Left / Right, dodging the red and orange blocks
*'S' is useless in this game. 
'SPACE' to start. 
'R' to restart after losing (crashing into a driver)
